# Expensy — Expense Tracker

A high-fidelity mobile app design for a personal expense tracking app, presented as four interactive screens on a design canvas.

## Screens

| # | Screen | Description |
|---|--------|-------------|
| 01 | **Dashboard** | Overview with total balance, income/expense summary, monthly budget progress, and recent transactions |
| 02 | **Add Expense** | Interactive numpad, category selector, note field, and save confirmation flow |
| 03 | **Transactions** | Month navigator, income vs. expenses summary, and transactions grouped by date |
| 04 | **Analytics** | Donut chart breakdown, category legend, and horizontal spending bars |

## Design System

- **Primary:** Blue `#1B45D0` — headers, active states, gradients
- **Accent:** Orange `#F56B1E` — CTA buttons, progress bars, the floating add button
- **Background:** `#EEF3FF` — light blue-tinted surface
- **Cards:** `#FFFFFF` with subtle blue-toned shadows
- **Typography:** [DM Sans](https://fonts.google.com/specimen/DM+Sans) — 300–700 weight

## Interactivity

- **Add Expense screen** — fully functional numpad, category toggle, note input, and success state
- **Transactions screen** — month navigation (← March / April / May →)
- **Canvas** — pan, zoom, and focus any artboard fullscreen (click the expand icon)

## Files

```
Expensy.html      — Main design file (all 4 screens)

README.md         — This file
```

## Usage

Open `Expensy.html` in a browser. Use the canvas controls to pan and zoom between screens, or double-click an artboard to view it fullscreen.
